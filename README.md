# 🤖 Smart Sentiment Analyzer

A lightweight Python OOP-based sentiment analysis script designed to evaluate text inputs and classify them into positive, negative, or neutral categories.

## ✨ Key Features
- **Object-Oriented Structure:** Built using modular Python classes for clean code.
- **Rule-Based Text Analysis:** Analyzes word patterns to determine overall text sentiment.
- **Interactive CLI:** Simple command-line loop for quick real-time testing.

## 🛠️ Built With
- **Language:** Python
- **Environment:** Visual Studio Code
